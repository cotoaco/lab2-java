# Задание 1. Имена
## Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное
представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван
Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может
быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.
Необходимо создать следующие имена:
• Клеопатра
• Пушкин Александр Сергеевич
• Маяковский Владимир
## Алгоритм решения
1. Создать класс `Name`.
2. Объявить свойства для хранения фамилии, личного имени и отчества.
3. Создать конструкторы для задания одного, двух или трёх параметров.
4. Создать методы для получения значений свойств.
5. Реализовать метод `toString()`, который формирует строку из непустых параметров имени.
6. Создать три объекта класса `Name` и вывести их на экран.

# Задание 3. Человек с родителем

Измените сущность Человек из задачи 2.2 добавив ему возможность задавать третий параметр:
Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо

фамилию необходимо сделать такой же как у отца.

как имя отца с добавлением суффикса “ович”.
Затем необходимо выполнить следующие задачи:
1. Создать людей: Чудова Ивана, Чудова Петра, Бориса
2. Сделать Ивана отцом Петра, а Петра отцом Бориса
3. Вывести на экран строковое представление всех троих людей.
## Алгоритм решения
1. Создать класс `PersonWithFather`.
2. Объявить свойства для хранения имени, роста и объекта отца.
3. Создать конструкторы с возможностью указания отца и без него.
4. Реализовать метод `setFather()` для установки отца.
5. В методе `toString()` проверить наличие отца и при необходимости сформировать фамилию и отчество.
6. Создать объекты Ивана, Петра и Бориса.
7. Установить родственные связи и вывести информацию о каждом человеке.

# Задание 4. Ломаная
## Текст задачи
Создайте сущность Ломаная, которая будет представлять собой ломаную линию (см. пример на
рис.1). Ломаная линия представляет собой набор следующих характеристик:
• Имеет массив Точек (из задачи 1.1), через которые линия проходит.
• Может быть приведена к строковой форме вида “Линия [Т1,T2,…,TN]”, где TN – это
результат приведения к строке Точки с номером N
Необходимо выполнить следующие задачи:
• Создать первую Ломаную, проходящую через точки {1;5}, {2;8}, {5;3}
• Создайте вторую Ломаную, чья первая и последняя Точка совпадает с таковыми у первой
Ломаной, но в качестве середины имеет точки: {2,-5}, {4,-8}
• Сдвиньте начало первой Ломаной таким образом, чтобы одновременно сдвинулось
начало второй Ломаной.
## Алгоритм решения
1. Создать класс `Point` для хранения координат точки.
2. Реализовать конструктор, методы получения координат, метод перемещения точки и метод `toString()`.
3. Создать класс `Polyline`, содержащий список точек.
4. Реализовать конструктор без параметров и конструктор с набором точек.
5. Реализовать метод `toString()` для вывода последовательности точек.
6. Создать две ломаные с общей начальной и конечной точками.
7. Переместить общую начальную точку и вывести обе ломаные повторно.

# Задание 6. Длина ломаной
## Текст задачи
Измените сущность Ломаная из задачи 4.9. Новые требования включают:
• В любой момент к имеющимся Точкам можно добавить новые Точки (добавляется либо
массив, либо просто перечень Точек, что приводит к получению нового массива,
содержащего как старые, так и новые значения).
• Может возвращать общую длину Ломаной.
Необходимо выполнить следующие задачи:
1. Создать Ломаную, проходящую через точки {1;5}, {2;8}, {5;3}
2. Вывести на экран её длину
3. Добавить (к ранее созданной Ломаной) точки {5;15}, {8;10}
4. Снова вывести на экран длину Ломаной
## Алгоритм решения
1. Использовать класс `Polyline`, созданный в предыдущем задании.
2. Реализовать метод `addPoints()` для добавления одной или нескольких точек.
3. Реализовать метод `getLength()`, который вычисляет расстояния между соседними точками и суммирует их.
4. Создать ломаную через три заданные точки.
5. Вычислить и вывести её длину.
6. Добавить две новые точки.
7. Повторно вычислить и вывести длину ломаной.

Расстояние между двумя точками вычисляется по формуле:

\[
d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}
\]

Общая длина ломаной равна сумме расстояний между всеми соседними точками.
